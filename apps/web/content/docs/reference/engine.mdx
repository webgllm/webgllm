---
title: The engine
description: The engine underneath, for experiments.
---

```ts
import { Engine, loadGguf, loadOnnx, loadTokenizer } from "webgllm"
```

`webgllm` also exports the engine that `WebGLLM` runs in its workers, for code that runs a model itself: benchmarks and experiments. To run `WebGLLM`'s models in a worker you start, use [`WebGLLMWorkerHandler`](/docs/reference/webgllm#a-worker-of-your-own) instead.

<Callout type="warn">
  Not covered by semver while the package is 0.x.
</Callout>

| Export | What it is |
| --- | --- |
| `Engine` | The WebGL 2 engine: runs a model's weights on a canvas |
| `loadGguf`, `loadOnnx` | Read GGUF or ONNX files into the engine's weights |
| `loadTokenizer` | The tokenizer and chat template |
| `httpSource`, `blobSource` | Byte sources the loaders read from |
| `loadVision`, `VisionEncoder` | A vision encoder's weights, and the encoder that runs them |
| `imageProcessorConfig`, `smartResize`, `toPatches` | An image as the patches the encoder reads |
| `setPromptBatch` | How many prompt tokens are read at a time (512 by default) |
| `defaultMemoryBudget` | The memory budget `WebGLLM` picks for the device |
| `WEBGL_TEXT_MODELS`, `WEBGL_MODEL_META` | The model catalog |
