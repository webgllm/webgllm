```ts
import { WebGLLM, WebGLLMError, WebGLLMWorkerHandler } from "webgllm"
```

The package also exports the OpenAI request and response types (`ChatCompletion`, `ChatCompletionChunk`, `ChatCompletionCreateParams`, …) and its own (`LoadProgress`, `ModelInfo`, `WebGLLMEventMap`).

## `new WebGLLM(options?)`

| Option | Type | Description |
| --- | --- | --- |
| `contextLength` | `number` | The context a completion loads a model for. The model's own when left out. |
| `memoryBudget` | `number` | Bytes all loaded models may take together. Picked from the device when left out. |
| `onProgress` | `(progress: LoadProgress) => void` | Every load's and download's progress. |
| `onMemoryClaim` | `({ model, bytes, signal }) => Promise<void> \| void` | See [Sharing memory](/docs/guides/sharing-memory). |
| `logLevel` | `"debug" \| "info" \| "warn" \| "error" \| "silent"` | Which worker messages reach the console. Default `"warn"`. |
| `worker` | `Worker` | A Web Worker of your own to run models in. See [A worker of your own](#a-worker-of-your-own). |

## A worker of your own

webgllm starts a Web Worker for each model it loads. To run models in a worker you start (bundled your way, or shared with your own code), write the worker with `WebGLLMWorkerHandler` and give it to `WebGLLM`:

```ts
// worker.ts
import { WebGLLMWorkerHandler } from "webgllm"

const handler = new WebGLLMWorkerHandler()
self.onmessage = (event) => handler.onmessage(event)
```

```ts
const worker = new Worker(new URL("./worker.ts", import.meta.url), { type: "module" })
const webgllm = new WebGLLM({ worker })
```

- The worker holds one model. Loading another replaces the one there once its running generation ends, whatever `keepLoaded` says; the replaced model's `unload` event has the reason `"evicted"`.
- `unloadModel` stops the model's generation and frees its GPU memory, and leaves the worker running. webgllm never ends a worker it didn't start. It resolves, after the model's `unload` event, once the worker has freed the memory.
- Completions take turns, each from its load to its last token, so two for different models don't replace each other midway.
- The handler ignores messages that aren't webgllm's, so your own code can share the worker.
- For several models loaded at once, make a `WebGLLM` for each worker (and share memory between them with `onMemoryClaim`), or leave `worker` out.
- Downloads (`downloadModel`) run in the same worker, beside the loaded model.

## `WebGLLM.isSupported()`

Returns `true` when the browser has what webgllm needs. See [Requirements](/docs/requirements).

## `chat.completions.create(body, options?)`

OpenAI's Chat Completions. Returns a `ChatCompletion`, or an async iterable of `ChatCompletionChunk` when `stream: true`. See [Chat and streaming](/docs/guides/chat-and-streaming).

| Option | Type | Description |
| --- | --- | --- |
| `signal` | `AbortSignal` | Stops the generation; rejects with an `AbortError`. |
| `onProgress` | `(progress: LoadProgress) => void` | The model's load progress, when this call loads it. |

## `loadModel(model, options?)`

Loads a model, downloading it first if needed.

| Option | Type | Description |
| --- | --- | --- |
| `contextLength` | `number` | Most tokens a chat may hold. Never more than the model's own. |
| `keepLoaded` | `boolean` | Never unloaded to make room for another model. |
| `onProgress` | `(progress: LoadProgress) => void` | |
| `signal` | `AbortSignal` | Stops the load, unless another call waits for it too. |

## `downloadModel(model, options?)`

Downloads a model's files into storage without loading them. Takes `onProgress` and `signal`; an aborted download resumes next time.

## `unloadModel(model?)`

Frees a model's GPU memory, or every model's with no argument. webgllm's own worker for the model ends; a worker of your own frees the model and stays running.

## `models`

| Method | Returns |
| --- | --- |
| `models.list()` | `Promise<ModelInfo[]>`: every supported model |
| `models.retrieve(id)` | `Promise<ModelInfo>` |
| `models.downloaded(id)` | `Promise<boolean>`: whether every file the model loads is in storage, or it's loaded. Reads storage only: no network request, no load |
| `models.delete(id)` | Removes a model's files from storage |

`ModelInfo` has `id`, `format` (`"gguf"` or `"onnx"`), `contextLength`, `size` (bytes to download), `downloaded`, `loaded`, `loadedContextLength`, and `supports: { tools, thinking, images }` (`images`: the model reads `image_url` parts). `list()` and `retrieve()` may ask the network for sizes and context lengths; to check only whether models are downloaded, use `downloaded()`.

## `addEventListener(type, listener)`

Events: `progress`, `loadstart`, `load`, `error`, `unload`. See [Events and errors](/docs/guides/events-and-errors).

## `LoadProgress`

| Field | Type | Description |
| --- | --- | --- |
| `model` | `string` | |
| `phase` | `"download" \| "load"` | |
| `progress` | `number` | 0 to 1 across both phases |
| `cached` | `boolean` | The files come from storage, not the network |
| `loadedBytes`, `totalBytes` | `number` | When known |

## `WebGLLMError`

An `Error` with a `code`. See [Events and errors](/docs/guides/events-and-errors#errors) for the codes.
