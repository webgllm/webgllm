---
title: Thinking
description: Reasoning output, and switching it on or off.
---

Models that think write their reasoning to `reasoning_content`, separate from the answer in `content`.

```ts
const stream = await webgllm.chat.completions.create({
  model: "unsloth/Qwen3.5-2B-GGUF",
  messages,
  reasoning: { effort: "high", max_tokens: 512 },  // "none" turns it off; max_tokens is an optional cap
  stream: true
})

for await (const chunk of stream) {
  const { reasoning_content, content } = chunk.choices[0].delta
}
```

Without streaming, the reasoning is in `message.reasoning_content`.

## Defaults

- LFM3 thinks by default; Qwen3.5 doesn't. `reasoning.effort` switches it through the chat template. OpenAI's `reasoning_effort` works too (the two must agree when both are set).
- `LiquidAI/LFM2.5-1.2B-Thinking-GGUF` always thinks and ignores `"none"`.
- `models.list()` says which models think (`supports.thinking`).

`reasoning.max_tokens` caps the reasoning; the model then answers. A budget without an effort turns thinking on. The `reasoning` object is OpenRouter's. Reasoning tokens count in `max_completion_tokens` and in `usage.completion_tokens_details.reasoning_tokens`.
