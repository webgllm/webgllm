title: Models
description: The models webgllm runs.
---

Pass a Hugging Face repository as `model`: any one whose architecture webgllm runs loads by name (LFM2 and LFM2.5, LFM3 and Qwen3.5, as a GGUF or an ONNX export). webgllm picks its weights (a Q4_0 GGUF first, or a 4-bit ONNX decoder), tokenizer and chat template (the repository's, else its base model's), thinking and tool-call format (from the chat template) and sampling (its `generation_config.json`) from the Hub. Another architecture, or a repository without weights webgllm loads, throws `model-not-supported` before anything downloads.

The catalog below holds known defaults for the models webgllm is tuned and tested on, such as sampling from their model cards. `webgllm.models.list()` returns it, plus any other model used on the page, with each model's size, context length, and whether it's downloaded or loaded.

| Model | Weights | Thinks |
| --- | --- | --- |
| `LiquidAI/LFM3-1.7B-GGUF` | Liquid AI's QAD Q4_0 GGUF (quantization-aware trained) | By default |
| `onnx-community/LFM3-1.7B-ONNX` | onnx-community's q4f16 export | By default |
| `unsloth/Qwen3.5-2B-GGUF` | unsloth's Q4_0 GGUF | When asked |
| `onnx-community/Qwen3.5-2B-ONNX` | onnx-community's q4f16 decoder | When asked |
| `LiquidAI/LFM2.5-1.2B-Instruct-GGUF` | Official QAD Q4_0 | No |
| `LiquidAI/LFM2.5-1.2B-Thinking-GGUF` | Official Q4_0 | Always |
| `LiquidAI/LFM2.5-350M-GGUF` | Official QAD Q4_0 | No |
| `LiquidAI/LFM2.5-1.2B-Instruct-ONNX` | Liquid AI's 4-bit ONNX export | No |
| `LiquidAI/LFM2.5-1.2B-Thinking-ONNX` | Liquid AI's 4-bit ONNX export | Always |
| `LiquidAI/LFM2.5-350M-ONNX` | Liquid AI's 4-bit ONNX export | No |
| `LiquidAI/LFM2-1.2B-Tool-GGUF` | Official Q4_0, tuned for tool calls | No |
| `onnx-community/LFM2-1.2B-Tool-ONNX` | onnx-community's q4f16 export | No |

Sampling defaults come from each model card. See [Thinking](/docs/guides/thinking) for switching reasoning on and off.

## Choosing one

- **LFM3 1.7B** is the default choice: it thinks, and has a 262,144-token context.
- **Qwen3.5 2B** answers directly unless asked to think.
- **LFM2.5 350M** is the smallest, for weak devices.

Every model takes [tools](/docs/guides/tool-calling).
