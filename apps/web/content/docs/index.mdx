---

WebGLLM runs language models in the browser on its own WebGL 2 engine, in a Web Worker. It works where WebGPU doesn't: Firefox on Android, older iPhones, and everywhere else. Its API follows OpenAI's Chat Completions.

```ts
import { WebGLLM } from "webgllm"

const webgllm = new WebGLLM()

const completion = await webgllm.chat.completions.create({
  model: "LiquidAI/LFM3-1.7B-GGUF",
  messages: [{ role: "user", content: "What is the capital of France?" }]
})

console.log(completion.choices[0].message.content)
```

The package is in early development (0.x); the API may change.
