WebGLLM runs language models in the browser on its own engine, in a Web Worker. It uses WebGPU where the browser has it and WebGL 2 everywhere else, so it also works where WebGPU doesn't: Firefox on Android and older iPhones. Its API follows OpenAI's Chat Completions, and it can also draw [pixel-art sprites](/docs/guides/image-generation).

```ts
import { WebGLLM } from "webgllm"

const webgllm = new WebGLLM()

const completion = await webgllm.chat.completions.create({
  model: "LiquidAI/LFM3-1.7B-GGUF",
  messages: [{ role: "user", content: "What is the capital of France?" }]
})

console.log(completion.choices[0].message.content)
```

The package is in early development (0.x); the API may change.
