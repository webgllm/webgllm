Tessera through webgllm's API

webgllm.images.generate in webgllm's own worker: a load (with progress), then each prompt as 1 and 4 sprites (seed 7), timed, then an unload. ?webgpu=0 runs on WebGL 2; &prompts=a,b; &hold=1 waits after each generation for a memory reading (see bench/README.md). Lines go to the server as TESSERA-API …; it ends with ALL DONE or ERROR.
