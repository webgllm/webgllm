Prompt prefix store

Two system prompts in turn (A, B, A, B), greedy, through the public API: the second A and B must answer as the first did, with the same log probabilities, and read only what follows their system prompt. Then a prefill (max_tokens: 0) and the same request after it. ?model=<id> (LFM3 1.7B GGUF by default), &cache=0 for no store (promptCacheBytes: 0), &words=<n> for each system prompt's length (1,700 words by default: about 2,400 tokens), &ctx=<n> (8,192 by default).
